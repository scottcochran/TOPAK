**2026.10.02** · genesis custodian: Scott, (1, 0) · supersedes G7 (`4480b3767df9eb17`) as the state of record · narrative: revision 11 of the Theory of Operation (`narrative/theory-of-operation.md`, tag `ToO-rev11`) stands, **not revised at G8**; where it and this checkpoint disagree, this document wins (§7, item 72)

**What G8 is.** The state of record, as G7 was: what each record says, what was ratified and by whom, what is owed,
and what is open. It is the first checkpoint under which a property of the corpus is **proved**, in the sense ADR-0046
§1 gives the word, and the first whose trusted base names a prover.

**What changed at G8.** G7 said, as every checkpoint since G3 had: no theorem is proved. Between G7 and G8 the TLA+
Proof System was integrated with the corpus and **thirteen of the fourteen modules under `spec/` gained a proof
module**, each extending a frozen module without editing it and proving every invariant that module states, under
named assumptions on its constants and under the hypothesis that the mutations which break each invariant are
absent: 2,417 obligations. **The method is declared and the prover is a row** (ADR-0046, Batch 25, C2 and C4): TLC
checks mutations and witnesses at small constants, TLAPS proves the invariants, *proved* and *checked* name the two,
the prover is trust root T-0045-31, and the proof modules and their results files are cited by digest and frozen.
MAP 2.3, open since 2026.09.12, is closed. Writing the proofs found five errors in the binding table, four in its
"Breaks under" column and one parameter premise, each corrected with TLC rows. **Nothing about the running reference
changed**: every proof is of a module, T-0045-28 is untouched, and the inventory at the reference is the same. After
G7's cut, Theory of Operation revision 11 and the glossary were revised against G7, two derived documents were
added, and a family of thirty diagrams was drawn against G7. **Every lease the reference issues is still rung 0.
Nothing is `Contained`.** The bootstrap trigger is still unmet, and remains optional.

### 2.9 The proofs

New at G8 (ADR-0046). For each of thirteen modules, `spec/<Module>_proof.tla` extends the frozen module and proves
its invariants as `Spec => []P`, each theorem taking as hypothesis only the mutations that break it, with a combined

**Results the drafting did not anticipate**, since G7:
1. **The proofs were cheap.** Every module states only safety, and each property is a flag or an append-only set

   guard each proof would rest on (`proof-method.md` §5). One invariant, `ContainedMeansConfined`, had to be invented:
   six clauses binding a lease to the guest generation it was granted against.
2. **A second derivation of the binding table found five errors in it.** Each theorem's hypothesis is the set of
   mutations that break it, written and checked independently of the table; where the two disagreed, TLC agreed
   with the proof. One was a transcription error the results file had already shown.
3. **The prover found a clause no TLC run could.** `NonComposition`'s NC1 needs that only admitted effects are
   recorded as via break-glass; the specification never reaches a state without it, so no model check sees the gap.
4. **An unnamed `ASSUME` is not a premise to the prover.** `RulesFloorBase` and `RulesFloorNV_rev5` state their
   non-vacuity facts that way; each is now a lemma proved from the definitions, with witnesses.
5. **The constants were not premises.** `MaxRound = 2`, which `Coupling` notes as needed, and `K < R`, which the
   binding table listed, are needed by neither unread bound. `K < R` is needed so that the bound can refuse at all.
6. **TLC counterexamples are not reproducible in their state counts.** With every worker searching, a run stops at
   the first violation found, which varies; outcomes reproduce, and every exhaustive row reproduces exactly
   (ADR-0046 R2).

**What these checks are.** A proved invariant holds of every behaviour of its module, under the module's named
assumptions and the theorem's hypothesis, for every constant those admit; it rests on T-0045-31. It is a claim about
the module and not about `mechanism/`. The mutations and witnesses are still TLC's, at small constants. The trace
validation is still drift detection against a model of the code, and a checked gate proof still certifies an
implication between two Cedar encodings, not the encoding.

## 5. Conventions carried at G8

G2 to G7's conventions stand. Added since G7:

- **Proved and checked are distinct words** (ADR-0046 §1). *Proved* names a claim the prover discharged and the
  hypotheses it was discharged under; *checked* names TLC's evidence. Neither is used of the running reference.
- **A proof module extends a frozen module and never edits it**, takes each mutation's absence as a hypothesis of
  the theorems it breaks, and is frozen with its results file once a record cites both by digest.
- **A proof results file binds the proof to its specification** by the digests of the EXTENDS chain it prints;
  `spec/proof-sync.sh` checks the binding. A changed specification is a successor module with a successor proof.
- **A mutated proof is not an artefact.** The non-vacuity check of a proof runs in a scratch copy and leaves no file.
- **A simulation result is never cited as a check**, and a counterexample row is cited for its outcome, not its
  state count.
- **The TLAPS wrapper is excluded from the manifest** with the TLC wrappers (`manifests/EXCLUDE`); the prover is
  identified by the binary digest each proof results file prints, as the checker is by the gate header.
