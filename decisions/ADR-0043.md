# ADR-0043 — Cell obligations for Run: what the Listener delivers, what each seat holds, and what the Observer must read

**Status:** Accepted (genesis) · 2026.09.30 · confirmation required (ADR-0029 C4) ⟨B20⟩ ⟨B22⟩ ⟨B25⟩
**Status note:** Ratified as drafted, in Batch 20 with ADR-0040 and ADR-0042 §1–§5; the `observer` seat keeps `Consult` (§2), by the custodian's decision. Confirmation required under **C4**: it resolves the provisional Run column of

---

## Context

ADR-0037 made the LTRO a cell of principals: a Thinker and an Observer hold seats, a Listener and a Reader are stages
with no Persona. ADR-0038 gave each cell its Observer and ADR-0039 coupled the Thinker's admits to it. All three were
written while Run's alphabet was provisional, and each left a Run-shaped blank.

- **ADR-0037 §2's Listener delivers "the admitted `Read` content".** Run admitted no read, and what a Run tool returns
  reached the Thinker with no stage named for it.
- **ADR-0037 §4's Run column is marked provisional.** It gives a `thinker` seat `RunInvoke` and `RunEmit`, and an
  `observer` seat `RunEmit`.
- **ADR-0039 finding 3 found that Observer rounds must overlap the Thinker's** and that nothing specifies how.
  ADR-0042 §5 now seals a Run round at lease expiry, which makes the question sharper: the final mark can only be
  reported after the Thinker's lease has ended.

ADR-0040 assigns the cell four obligations. This record states them.

---

## Decision

### 1. The Listener delivers three things, and nothing else reaches the Thinker

In Run the Listener delivers **the task, the content of each admitted `Consult`, and the result of each admitted
`Actuate`.** That list is the Thinker's whole ingress.

- **It is still a stage.** It has no Persona, makes no choice and holds no alphabet (ADR-0037 §2). At the reference it
  is the node side of `Consult` and of `Actuate`'s return, as it is the node side of `Read` in Build (ADR-0036 §3).
- **Every item is on the record.** A `Consult` is an admit in the log, naming a digest. A result is named by digest in
  the `Actuate` record (ADR-0042 §3, §4). The task is the grant's.
- **It adds nothing to the trusted base**, because the mechanism already admits and records each item.

**Whether what it delivers is poisoned is not the Listener's to decide.** It delivers what was admitted. A judgment
about content is an Observer finding (ADR-0007).

### 2. Alphabets by seat kind, in Run

| Kind | Run | Why |
|---|---|---|
| `thinker` | `Consult`, `Actuate`, `Report` | The whole alphabet. It is the only seat that acts |
| `observer` | `Consult`, `Report` | `Report` carries its heartbeats and its findings. `Consult` lets it read the pinned objects its Thinker consulted *(drafter's choice)* |
| `grant` | None | Only Build seats vote (ADR-0037 §4, unchanged) |

**Only a `thinker` seat holds `Actuate`.** It is Run's one variant that runs anything, and it joins `Draft`, `Invoke`
and `Submit` in `B10-only-thinkers-author` (ADR-0041 §1). The grant path refuses an alphabet outside the kind's row,
and the floor refuses the action at admit, so the rule is enforced twice, as in Build.

This table replaces the Run column of ADR-0037 §4. The Build column is not touched.

**Giving an `observer` seat `Consult` is new.** The provisional column gave it emission only. An Observer judging what
a Thinker did with an object needs the object, and a read of pinned content by digest is no effect and needs no
coupling. An Observer's `Consult` is scoped to the same Run root as its Thinker's and reaches nothing the Thinker
could not.

### 3. The Thinker's decoder targets this alphabet

The decoder ships in the Thinker's Persona and the validator stays in the mechanism (ADR-0018). **A Run Persona's
decoder emits `Consult`, `Actuate` and `Report`, and nothing else.** A decoder that emits a retired name produces a
request the validator refuses (ADR-0042 §1).

The rename therefore reaches every Run Persona. That is decoder–alphabet compatibility (G5 item 17), and this record
does not settle it: it says which alphabet the decoder must meet, not how a Persona is checked against a change to it.

**The Reader is unchanged.** Its two outputs are facts the cell Observer consumes, and conformance may admit only at a
rung that attests inference (ADR-0037 §3).

### 4. The Observer reads every record the mechanism writes

**A cell Observer's watermark is over the sequence of ADR-0042 §2.** To move its mark past a number honestly, it has
read the record at that number: an `Actuate` record, with its inputs and its result, or a `Report`.

- **The heartbeat is a `Report`** with the fixed schema of ADR-0039 §1, carrying the watched topic and the watermark.
  ADR-0039 says the heartbeat is `Emit`ted; in Run the variant is `Report`.
- **A finding is a `Report`**, and it only subtracts (ADR-0007). Observers watching one principal combine by any-of
  (ADR-0038 §5).
- **An Observer's own `Report`s are not coupled** (ADR-0039 §2; ADR-0041 §1's R3 names `thinker` seats), or the rule
  would refuse the report it exists to receive.
- **What the mark asserts is reading, not approval.** Coverage is not a "no finding" attestation (ADR-0039 §3;
  ADR-0024 §2).

**The Observer reads results as well as calls.** A result is ingress to the Thinker (§1), and an injection carried by
a tool's return is visible in the `Actuate` record before the Thinker's next effect is admitted, given `K`. This is
the first place the design puts a second reader on Run's ingress.

### 5. The Observer's lease must reach the seal

A Run round seals when the Thinker's lease ends (ADR-0042 §5), and round `r+1` is granted only after a cell Observer's
mark reaches that seal (ADR-0039 §2). **So a cell must hold an Observer lease that is live after the Thinker's has
ended**, for long enough to read the tail and report the final mark.

- **Marks are kept by seat and by round** (ADR-0039 §1), so an Observer's next lease continues where its last stopped.
  The obligation can be met by one lease that outlasts the Thinker's or by a later one.
- **An Observer that never reaches the seal stalls its own cell**, and nothing else (ADR-0038's bounded reach). The
  Thinker holds no lease while it waits and burns no TTL (ADR-0039 §2).
- **How rounds are laid out is a deployment's.** That a layout must meet this obligation is the archetype's. No record
  says how Observer rounds are granted against Thinker rounds, and this record does not either (finding 1).

### 6. The correlator reads the same records, and is never coupled

The correlator is in `W(p)` for every principal in its domain (ADR-0038 §2), so it receives `Actuate` records and
`Report`s from every cell. It may read facts only, which ADR-0038 §3 permits as a narrowing; the record's envelope is
built so that a facts-only reader still sees each call, its tool and the digests of its inputs and result (ADR-0042
§3). **No admit waits on it** (ADR-0039 §4).

### 7. What the cell cannot cover, and what is inherited

- **Collusion stays open.** A colluding Observer sends heartbeats, reports a watermark past every record, and finds
  nothing. Counting invocations does not change that: the mark is still its own assertion (ADR-0039 §5). What covers
  collusion, as far as anything does, is lineage independence (ADR-0016 §5, ADR-0035).
- **D-0037-1** (no Observer in a cell), **D-0038-1** (the shared group only) and **D-0038-2** (no correlator) are
  inherited unchanged. Under coupling the first two are usable in Run only with D-0039-1, as ADR-0039 §7's composition
  note says.
- **No new degeneracy.** An `observer` seat without `Consult` is a narrowing of §2's row, which a lease may always
  make (ADR-0031 §4), and needs no declaration.

### 8. Ratification condition

- **ADR-0040 and ADR-0042 §1 to §5 are ratified first, or together with this record.** ADR-0042 §6 need not be.
- **The grant path and the floor refuse the same thing**: an `observer` or `grant` seat in Run is refused `Actuate` at
  grant, and by `B10-only-thinkers-author` at admit. `Seats.tla` is cited by digest in an accepted record, so the
  restated check is a new module or is carried by ADR-0042 §8's.
- **The reference**, with an ADR-0033 addendum: a scripted Run cell, in the shape of ADR-0036's occupant. The Thinker
  performs a `Consult`, an `Actuate` and a `Report`. The Observer reads the `Actuate` record, moves its mark across
  it, and reports a heartbeat after the Thinker's lease has expired. **Two behaviours, each seen:** the next round
  refused until that final mark arrives, and granted after it.
- **The dependent entries** in ADR-0037 §2 and §4 and in ADR-0039 §1 are drafted.

## Options considered

| Option | Disposition |
|---|---|
| **Keep the provisional column**: an `observer` seat holds emission only | Not taken *(drafter's choice)*. An Observer that cannot read what its Thinker consulted judges effects without their inputs. The custodian may strike `Consult` from the row; nothing else in the record depends on it |
| Give the Observer `Actuate`, to probe a tool | Rejected. An Observer that acts is a second Thinker with no Observer of its own. ADR-0037 §4's rule that only a `thinker` seat runs anything is kept |
| Make the Listener a seat, so ingress has a principal | Rejected by ADR-0037 §2, and not reopened. It makes no choice, so it has nothing to attribute |
| A seat for the tool host | Not taken. It runs on the mechanism's side and belongs in the TCB declaration (ADR-0042, Open obligations; **ADR-0045 T-0045-25**, Batch 22 ⟨B22⟩) |
| Fix the round layout here: the Observer's lease outlasts the Thinker's by a stated tail | Not taken. It is a number with no measured basis, and a placeholder in a ratified record acquires authority it was never given (ADR-0039, R3 note) |
| Couple the Thinker's grant to a live Observer lease as well as to coverage | Not decided here. ADR-0035 §5 keeps independence checks off the grant path; whether a liveness check belongs there is the round-layout record's |

## Consequences

**Positive**
- **ADR-0037 §4's Run column stops being provisional.**
- **Run's ingress has a stage and a list**, and tool results are on it.
- **A second reader sees every tool result** before the Thinker's backlog can pass `K`.
- **ADR-0039 finding 3 becomes an obligation** with a test (§8), where it was an observation.

**Negative**
- **The Observer reads payloads**, results included, so it sees what the Thinker sees. An injection that turns a
  Thinker may turn its Observer. Lineage independence is what stands against that, and its criterion is not in force
  (ADR-0035, Proposed).
- **A cell needs an Observer lease after every Thinker round**, which is more grants and more heartbeats on the log
  (ADR-0039 §6's throughput cost).
- **Round layout is still unspecified.** This record makes it matter more.
- **One author, and no options discussion on the cell.**

---

## Findings

1. **No record lays out rounds.** ADR-0031 makes a lease one round and ADR-0039 couples two seats' rounds to each
   other. Which is granted first, for how long, and what happens at the boundary are decided nowhere. ADR-0039 finding
   3 found it; ADR-0042 §5 and this record's §5 depend on it.
2. **ADR-0037 §2 gives the Listener's placement as "the mechanism's ingress path"**, which already covers a tool's
   return. Only its description, "the admitted `Read` content", was Build-shaped.
3. **An Observer with `Consult` has an ingress of its own**, and no stage is named for it. A cell's Observer has no
   Listener in ADR-0037's table. Its ingress is the topic it watches, by the ACL, and now the Run root.
